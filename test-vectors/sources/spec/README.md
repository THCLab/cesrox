# Examples from the CESR specification

Hand-written vectors taken from the examples in the CESR specification
(kswg-cesr-specification, `spec/spec-body.md`, v1.1 at commit `bad6edd`).
They are copied verbatim, with annotations removed where the `stream` field
needs plain CESR; the annotated form is kept in `annotated`.

When the specification changes an example, update the vector by hand and
record the new commit here.
